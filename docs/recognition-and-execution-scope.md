# نطاق التنفيذ ومشروع «أنتِ تستحقين الشكر»

تطوير إضافي للبوابة الأصلية وSupabase، بتاريخ 15 أكتوبر 2026.

## التغييرات

- نطاق تنفيذ إلزامي للفعالية والورشة والمبادرة والملتقى. النشاط الخارجي يتطلب جهة منظمة ومستضيفة؛ الداخلي يمسح الجهتين المخفيتين. الأنواع الأخرى محفوظة.
- تخزين النطاق والجهتين في أعمدة Supabase مع نسخة متطابقة في تفاصيل التقرير. حقول الورش القديمة aliases للنطاق والجهة المنظمة، وليست مصدر بيانات مستقلًا.
- طلبات الورش والبرامج المعتمدة تدعم الجهة المستضيفة وتُعبأ بياناتها عند بدء توثيق التنفيذ. مركز الدعم يحصي سجل التوثيق الأصلي.
- مشروع التكريم يظهر في المشاريع والنموذج والأرشيف. يدعم حسابات متعددة وأقسامها، ونوع التكريم وسببه، وتقديرات متعددة، وساعات سعادة لكل مكرمة، والجهة المقدمة والملاحظات. الصور والشهادات تستخدم التخزين الخاص الموجود: حتى 10 صور و5 مرفقات PDF.
- الخادم يتحقق من الحسابات ويحفظ لقطة الأسماء والأقسام وقت التكريم، ولا يثق بالأسماء التي يرسلها المتصفح.
- الأرشيف يبحث بأسماء المكرمات وأقسامهن، مع فلاتر النطاق ونوع التكريم والمشروع والتاريخ. أعداد الداخلي والخارجي تتبع نتائج الفلاتر، والسجلات القديمة غير المحدد نطاقها لا تُصنف افتراضيًا.
- لوحة recognition.html تعرض عدد الفعاليات، والمكرمات دون تكرار حسب معرف الحساب، ومرات الاستفادة، والتكريم لكل موظفة وقسم ونوع، والساعات، والتجميع الشهري والفصلي والسنوي الدراسي. فعالية تشمل عدة أقسام تُحسب لكل قسم شارك فيها؛ فلا يُجمع توزيع الأقسام باعتباره إجمالي الفعاليات.
- تنزيل تقرير تجميعي رسمي PDF وExcel فعلي .xlsx ببيانات كل مستفيدة وإحصاءات التجميع. تقارير التكريم تعرض جميع البيانات والصور، وتُدمج صفحات مرفقات PDF الفعلية في التنزيل. المرفق المحمي بكلمة مرور أو غير الصالح يوقف التصدير برسالة واضحة.

## الصلاحيات والبيانات

- لا تغيير لحسابات المستخدمين أو الأدوار أو صلاحيات المجالات الحالية.
- إضافة وقراءة التكريم متاحتان للمديرة وحصه وفق سجل القيادة المعتمد. جدول recognition_access الخاص مخصص لتفويض مستخدمات أخريات لاحقًا بقرار الإدارة؛ لم تُضف إليه تفويضات تلقائية.
- سياسات RLS تقييدية تمنع تسرب بيانات التكريم عبر سياسات التقارير العامة، وتمنع الإدخال غير المخول. دليل الحسابات لا يعرض البريد أو بيانات الدخول، ولا يُتاح إلا للمخولات بالإدخال.
- الحذف المنطقي والاستعادة وسجل التدقيق الأصلي باقية ومقصورة على المديرة وحصه. لا حذف فعلي ولا تعديل للسجلات القديمة.
- الساعات تُمنح بالتساوي لكل مكرمة في الفعالية: ساعة × ثلاث مكرمات = ثلاث ساعات. يمكن إنشاء توثيق مستقل عند اختلاف الساعات بين المستفيدات.
- الفلترة بالاسم والقسم في لوحة المشروع تختار فعاليات التكريم المطابقة؛ إجمالي الفعالية يشمل جميع مكرماتها.

## التحقق

- اختبارات PostgreSQL محلية تطبق migrations الفعلية وتفحص جميع الأنواع الداخلية والخارجية، ورفض غياب الجهتين، والتكريم الفردي والجماعي والتحقق من الحسابات والساعات، وRLS، والحذف والاستعادة، وترابط الورشة المعتمدة مع المركز دون تكرار.
- اختبارات DOM للنطاق والحقول الشرطية والاختيار المتعدد والاستعادة؛ اختبارات البحث بالأسماء والأقسام ومرشحات الأرشيف والإحصاءات.
- اختبارات حفظ الصور واستعادة محاولة الحفظ وفقد الرد ومنع التكرار؛ اختبارات المركز والنماذج السابقة.
- تصدير PDF قصير وكامل بالبيانات التجريبية والصور ودمج المرفقات؛ تحقق من عدد الصفحات وفحص بصري للمخرجات. فحص ZIP وXML لملف Excel.
- على Supabase الأصلي: نجح حفظ واسترجاع 8 سجلات للنطاق داخل transaction، ورفض نقص المستضيفة، وتكريم فردي وجماعي بإجمالي 4.5 ساعة، وروابط الأرشيف، ومنع القراءة والإضافة والحذف غير المخول، والحذف المنطقي والاستعادة. أُلغيت transaction كاملة فلا تبقى بيانات الاختبار.
- لم يُنفذ تسجيل دخول جديد ورفع ملف فعلي عبر متصفح منشور في هذه الجولة. فحص الصلاحيات على الخادم استخدم أدوار PostgreSQL وclaims داخل transaction؛ لا يعادل تجربة تسجيل الدخول على كل جهاز.
