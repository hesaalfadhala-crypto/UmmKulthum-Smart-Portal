# عرض أجندة الفعاليات المختصر — 25 أكتوبر 2026

التعديل يخص العرض والتصدير فقط؛ لم تتغير الجداول أو RLS أو نموذج الفعالية أو مواعيدها.

- وحدة `agenda-display.js` تجمع الفعاليات المعتمدة حسب اليوم والفترة، وتُسقط الفترات الفارغة. تعرض العنوان للطابور والفسحة عند وجود فعاليات فيهما فقط؛ الأحداث الأخرى دون عنوان فترة.
- العرض الأسبوعي وPDF لا يحجزان صفًا لليوم الخالي. عند خلو الأسبوع كله تظهر رسالة واضحة. بطاقات الأيام الخمسة تحافظ على اليوم والتاريخ حتى لليوم الخالي دون شرطات أو عناوين فترات فارغة.
- اسم الفعالية عريض أخضر Cairo ويلتف دون قص، والبيانات الثانوية أصغر. ارتفاع بطاقة القص يتكيف مع المحتوى ضمن أقصى ارتفاع تختاره المستخدمة؛ تحفظ خيارات القياس الحالية.
- معاينة الطباعة، PDF والطباعة المباشرة تستخدم لوحات الرسم نفسها. الطباعة A3/A4 أفقية للجدول وA4 للبطاقات، دون فاصل صفحة إضافي بعد آخر صفحة.
- زرا الطباعة يفتحان نافذة الطباعة؛ زرا تنزيل الجدول/البطاقات PDF مستقلان.

التحقق: `node --test --test-concurrency=1 tests/agenda/*.test.mjs` (9 اختبارات ناجحة). يشمل الحفظ والتعديل والاعتماد والصلاحيات والربط بالتوثيق القائمة، وحالات العرض الخمس، وإخفاء غير المعتمد، والنص الطويل، وأبعاد PDF، وإعادة استخدام اللوحات في نافذة الطباعة. رُوجع الرسم العربي للبطاقة وملف A4 بصريًا. لم تختبر طابعة فعلية أو حوار طباعة iPhone في هذه الجولة. جميع بيانات الاختبار وهمية محلية.
